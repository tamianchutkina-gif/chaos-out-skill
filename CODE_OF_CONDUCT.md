# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good intent, keep discussions about the work.
Harassment, personal attacks, and publishing others' private information are
not tolerated.

Reports can be made privately through GitHub's
[report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
flow or by contacting the maintainer via their GitHub profile. Reports are
handled confidentially.
